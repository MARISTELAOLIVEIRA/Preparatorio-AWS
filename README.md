# Preparatório AWS Cloud Foundations · Profa. Maristela

Site do preparatório AWS Cloud Foundations da AWS Academy da Faculdade de Tecnologia e Inovação Senac-DF.

## O que tem no site
Próximo encontro (atualiza sozinho pela data), cronograma do semestre, acompanhamento de progresso no Cloud Foundations e na reta final, vídeos de apoio, treino “Qual é o serviço?”, mini-simulado, passo a passo da prova e do voucher, área da turma (links do Teams, sem senha) e links úteis.

## Como atualizar
- **Datas, encontros, vídeos e perguntas:** edite o bloco "DADOS (edite aqui)" no início do script do `index.html`.
- **Links da área da turma e dos vídeos:** edite `AREA_TURMA` e `VIDEOS_LINKS` no script do `index.html`. Não há senha: os links (Teams, gravações) só abrem com a conta institucional.
- **Novo semestre:** atualize as datas em `ENCONTROS` e os links da área da turma.

## Publicação
GitHub Pages, branch `main`, pasta raiz. O `gerador-area-turma.html` (da época da senha) não é mais usado e não deve ser publicado.
