# Preparatório AWS Cloud Foundations · Profa. Maristela

Site do preparatório AWS Cloud Foundations da AWS Academy da Faculdade de Tecnologia e Inovação Senac-DF.

## O que tem no site
Próximo encontro (atualiza sozinho pela data), cronograma do semestre, acompanhamento de progresso no Cloud Foundations e na reta final, vídeos de apoio, treino “Qual é o serviço?”, mini-simulado, passo a passo da prova e do voucher, área da turma protegida por senha e links úteis.

## Como atualizar
- **Datas, encontros, vídeos e perguntas:** edite o bloco "DADOS (edite aqui)" no início do script do `index.html`.
- **Links da turma e dos vídeos (área protegida):** abra o `gerador-area-turma.html` no seu computador, preencha, clique em Gerar e cole o resultado na linha `const AREA_TURMA="…";`.
- **Novo semestre:** atualize as datas em `ENCONTROS` e gere a área da turma com uma senha nova.

## Publicação
GitHub Pages, branch `main`, pasta raiz. Não publique o `gerador-area-turma.html`.
