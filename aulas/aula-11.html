EC1 · estudo de caso

O quadro de ideias da Ingresso Candango

O site da Ingresso Candango aguentou a venda do Festival do Cerrado (aula 10). Na reunião seguinte, a equipe encheu um quadro de ideias:

  1. Uma fila para nenhum pedido se perder na abertura da venda.
  2. Um SMS avisando que o pagamento foi aprovado.
  3. Um assistente no site que responde às dúvidas dos clientes.
  4. O ingresso lido em voz alta, para quem não enxerga.
  5. Legendas automáticas nos vídeos dos shows.
  6. Saber se os comentários dos clientes são elogios ou reclamações.
  7. Consultar com SQL os arquivos de registro guardados no S3, sem montar um banco.
  8. Criar toda a infraestrutura das aulas anteriores a partir de um arquivo, igual toda vez.

Para pensar

  1. Precisa programar uma inteligência artificial do zero para ler o ingresso em voz alta?
  2. Por que montar a infraestrutura com um arquivo é melhor do que clicar no console toda vez?

Fontes: guia da CLF-C02, serviços que caem e Amazon Q, consultados em 04/11/2026.

IA com consciência: a IA ajuda, mas quem confere é você. Uma legenda automática pode errar nomes de bandas; alguém da equipe revisa antes de publicar.

Como é no Azure: os serviços prontos ficam no Azure AI Services (fala, visão, linguagem, tradução), e a IA generativa no Azure OpenAI.

D1 · demonstração

A AWS pela linha de comando

No vídeo eu faço junto com você. A página do Learner Lab tem um terminal com a AWS CLI pronta.

Faça assim:
  1. Abra o Learner Lab e clique em Start Lab. Espere a bolinha ao lado de AWS ficar verde.
  2. Clique no terminal da própria página do laboratório e digite aws --version. Apareceu a versão? A CLI está pronta.
  3. Digite aws ec2 describe-regions --output table. Lembra da aula 3? São as regiões, agora pela linha de comando.
  4. Digite aws s3 ls. Lista os seus buckets (vazia, se você apagou o da aula 7).
  5. Abra o console e procure o Amazon Polly. Se o laboratório liberar, escreva uma frase em português, escolha uma voz e clique para ouvir.
Teste:
  1. Qual é a diferença entre clicar em Create bucket no console e digitar um comando? Qual dos dois dá para repetir igual cem vezes?
  2. No fim, End Lab.

O Learner Lab não libera todos os serviços. Se o Polly ou outro serviço der erro de permissão, é esperado: o importante é a linha de comando. As telas mudam de vez em quando: procure a mesma ideia.

P1 · pegadinha de prova

Nomes que se parecem

Par que confundeA diferença
Polly e TranscribePolly: texto → voz. Transcribe: voz → texto.
SQS e SNSSQS: a mensagem espera na fila. SNS: o aviso sai na hora para todos os assinantes.
Comprehend e TextractComprehend: entende o texto (sentimento, assunto). Textract: tira o texto de um documento escaneado.
Rekognition e TextractRekognition: o que tem na imagem. Textract: o que está escrito no documento.
CloudFormation e Elastic BeanstalkCloudFormation: você descreve toda a infraestrutura num arquivo. Beanstalk: você só manda o código.
Athena e RedshiftAthena: SQL direto nos arquivos do S3, sem servidor. Redshift: um data warehouse para análises grandes e frequentes.
